⚗️ ACPM Local Dev Shell

Bypass the login wall for LOCAL debugging of labor/payroll against the emulator. Production is untouched — this page and dev/ are excluded from hosting deploys.

1 · Start the emulator

npx firebase emulators:start --config dev/firebase.dev.json --project acpm-project-system-qa

Database emulator listens on 127.0.0.1:18300 with dev/dev-rules.json (open, dev-only).

2 · Seed demo data

node dev/seed-dev-data.js

Creates users/dev-boss + project dev-pilot with workers, attendance, advances, and an archived payroll log.

3 · Open the app (no login)

Open Workspace — dev-pilot Open Dashboard Login page (auto-enters)

Clicking any of these activates the dev session flag (sessionStorage.acpm_dev_shell) so you can navigate freely for the rest of the session.

How it works / security

Fail-closed: dev/dev-bypass.js only installs mock auth + emulator wiring when the hostname is localhost/127.0.0.1 (or empty) and ?dev=1 or the session flag is present. On any remote host it does nothing — real login and real rules apply.

Data isolation: the database is redirected to the local emulator (127.0.0.1:18300). It never touches staging or production data.

Not deployable: dev/** and dev.html are in firebase.json hosting ignore, so the shell cannot ship. The scripts/dev_shell_static_qa.js gate enforces this.

Exit: use the purple DEV SHELL badge (bottom-right) → exit, or remove the query param.
